# Хроники Звёздного Пепла — прототип

Мобильная аниме-RPG с автобоем на Godot 4.3. Персонажи и враги рисуются кодом в стиле чиби, без картинок.

## Как запустить
1. Скачайте Godot 4.3: https://godotengine.org/download
2. В Godot: «Импорт» → выберите `project.godot` в этой папке → «Запустить» (F5).
3. Для телефона: Проект → Экспорт → Android (нужны шаблоны экспорта и Android SDK).

## Что есть
- Сюжетные сцены перед этапами 1, 3, 5, 7, 10, 11, 20, 30 (тап по панели — следующая реплика).
- Автобой отряда из 4 героев: шкала хода по скорости, энергия, ультимейты по тапу или «Авто-ульт», скорость ×2.
- Стихии: Огонь > Природа > Вода > Огонь, Свет ↔ Тьма.
- Этапы с ростом сложности, босс на каждом 10-м, золото за победу, улучшение уровня отряда.
- Снаряжение (клинок, доспех, амулет) четырёх редкостей выпадает с этапов; экран «Отряд» показывает статы и вещи, кнопка «Надеть лучшее» раздаёт их героям.
- Башня Пепла (открывается после 10-го этапа): бесконечные этажи, босс каждый 5-й этаж, гарантированная вещь и двойное золото за этаж.
- Ежедневные задания: 4 задания с наградой золотом, сброс каждый день.
- Возвышение героев: звёздная пыль за боссов, башню и задания; до 5 звёзд, +8% к HP и атаке за звезду, пассивка на 3-й звезде и личная сцена героя на 1-й.
- Сохранение и idle-доход до 12 часов, пока игра закрыта.

## Файлы
- `data.gd` — герои, враги, боссы, сюжет, формулы прогрессии.
- `equipment.gd` — снаряжение: выпадение, редкость, бонусы, автоэкипировка.
- `quests.gd` — ежедневные задания.
- `ascension.gd` — возвышение героев: звёзды, пассивки, личные сцены.
- `chibi.gd` — рисование чиби-портретов героев и врагов.
- `battle.gd` — логика боя без узлов (удобно тестировать).
- `main.gd` — экран боя, интерфейс собирается в коде.
- `test_battle.gd` — проверка баланса:
  `godot --headless --path . --script res://test_battle.gd`
